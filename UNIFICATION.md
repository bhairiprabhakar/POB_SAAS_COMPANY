# Codebase Unification — single app with full functionality

Goal: turn this repo into **one application** that keeps ALL functionality of
both the legacy single-company app (`app/`) and the multi-tenant SaaS
platform (`saas/`), with one frontend (the React SPA in `web/`). The legacy
`app/` tree and the Jinja templates are deleted in the final batch.

## Target architecture (end state)

- **One backend:** `saas/` — the merged app (FastAPI, JWT, per-tenant DBs).
- **One frontend:** `web/` React SPA — all legacy portal features reimplemented as pages.
- **No `saas → app` or `app → saas` imports** — shared code lives in `saas/`.
- Legacy single-company functionality becomes a **statement/credits domain**
  inside every tenant DB (documents, extraction, credits billing, L1/L2
  dedup, AI model config + costing).

## Acceptance criteria per batch

- Every batch keeps **both** current apps running (legacy keeps serving until Batch 4).
- No new imports across the `saas↔app` boundary (grep gate in Batch 1+).
- Schema changes go through TENANT_DDL/TENANT_PATCHES with a `SCHEMA_VERSION` bump (the pob_required incident must not repeat).
- Each migrated feature passes the existing E2E/verify scripts or a ported equivalent.
